PRESENTAZIONE TESI - 5 MINUTI
Samuele De Santis

5 slide, senza copertina aggiuntiva.

FILE
- index.html: versione animata offline. Aprirla con Chrome, Edge o Firefox.
- tesi-5min.pptx: PowerPoint modificabile, con comparse native al clic.
- tesi-5min-statico.pptx: copia modificabile senza animazioni.
- tesi-5min.pdf: copia di sicurezza, 5 pagine complete.
- note-relatore.md: discorso e riferimenti, presenti anche nelle note del PPTX.

COMANDI HTML
Clic / freccia destra / spazio: passaggio successivo.
Freccia sinistra: passaggio precedente.
Page Down / Page Up: cambia slide. 1-5: vai alla slide.
Home / End: inizio e fine. A: mostra tutta la slide.
F: schermo intero. N: note. T: cronometro. P: stampa.

POWERPOINT
Avviare la presentazione con F5. I clic mostrano gruppi di elementi.
Per conservare i caratteri originali, installare i font della cartella fonts.
Eseguire una prova in Microsoft PowerPoint sul computer della discussione.
Le comparse sono native OOXML. Non sono state eseguite in Microsoft PowerPoint.
I file sono stati controllati strutturalmente e resi anche con LibreOffice.
